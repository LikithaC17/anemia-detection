7. IDENTIFIED PROBLEMS & RECOMMENDATIONS FOR PHASE 2
----------------------------------------
Problem 1: Class Imbalance
  - Non_Anemia has far more samples than Anemia across modalities, especially Palm (~2,438 vs 380).
  - Recommendation: Stratified splitting, class weighting, or balanced sampling/augmentation in subsequent phases.

Problem 2: Directory Naming Inconsistency in Eye Modality
  - Anemia Eye uses 'left_crop' / 'right_crop', while Non_Anemia Eye uses 'left_conjunctiva' / 'right_conjunctiva'.
  - Recommendation: Create a unified preprocessing / loading manifest that maps anatomy consistently.

Problem 3: Participant Overlap Across Digits and Hands
  - Participant IDs (P001, etc.) appear across multiple images (Left Palm, Right Palm, and 10 Nail Bed images).
  - Recommendation: Ensure patient-level (GroupKFold / Subject-level) data splitting to prevent severe data leakage.
